# Woningmarkt NL — build brief for Claude Code
Build a free, bilingual (NL root, EN mirror under /en/) Dutch housing-market analyser. Static site: `node build.mjs` (zero npm deps, Node 20) writes prebuilt HTML into `dist/`. Hosted on GitHub Pages at https://cerberostech.github.io/woningmarkt/ (base path /woningmarkt/!).

## Data (already fetched — DO NOT invent any number; missing => show "geen officiële bron / no official source")
- data/housing.json from scripts/fetch-data.mjs: CBS 83625NED avg sale price per region/year (prices[code][year]; codes NL01, PV20.., GM0363..), 85792NED quarterly (recent), 85791NED by dwelling type nationally (byType: houses vs apartments), Kerncijfers wijken en buurten 2025 (kern[GMxxxx]: WOZ avg x1000, % eengezins/meergezins, % koop/huur, cars per household), 83704NED dwelling stock by floor-area CLASS and type (area.data[code].all/house/apartment[classKey]). sources{} has titles, modified dates, URLs, license.
- data/geo-gemeente.json, data/geo-provincie.json: PDOK CBS gebiedsindelingen 2025 (properties.code = GM0363 / PV26 etc.).
- data/rates.json: ECB/DNB average bank mortgage rates NL, new business, by fixation period, monthly.
- data/lender-rates.json: editorial lender rates (only ABN AMRO captured; others "pending terms check" → show as such, no numbers).
- data/params-2026.json: sourced 2026 rules (Trhk financieringslast tables, energy-label extras, toetsrente 5%, NHG €470k/0.4%, overdrachtsbelasting 2%/0%/8%/10.4%, starter cap €555k, ages 18–<35). Verification: income €46,500 @5% → 24.6% → max mortgage €177,573 (matches SEH).
- Rooms and parking: NO free official regional source. Do not show them as data. Say so explicitly on map/city pages and methods page. Cars per household may appear only labelled "context, not a parking measure". Floor area: show distribution by class (e.g. share 75–100 m², median class) — do NOT present a precise average m².
- Apartments vs houses price split exists ONLY nationally (85791NED); say so per municipality.
- CBS warns average prices are not a price index; mention it. NEVER say "real-time"/"live". Use "Laatste officiële CBS-cijfers (bijgewerkt <date>)".
